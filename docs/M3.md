# M3: Offline Dataset Pipeline

## Scope

M3 provides a reproducible pipeline for the six canonical D4RL MuJoCo v2
datasets: `halfcheetah`, `hopper`, and `walker2d` in `medium-v2` and
`medium-replay-v2` variants. It covers registry, explicit acquisition,
local-only loading, HDF5 schema validation, episode-boundary analysis,
deterministic sampling, and inspection. It performs no training, no
normalization, no preprocessing, and implements no RL algorithm.

**NOT IMPLEMENTED:** IQL, CQL, TD3+BC, ReDo, plasticity interventions,
adaptive controllers, reward/observation normalization, and any training.

## Provenance (no substitution)

The authoritative source is the official D4RL registry
(`Farama-Foundation/D4RL`, `d4rl/infos.py`), which maps each `*-v2` dataset
to an `http://rail.eecs.berkeley.edu/datasets/offline_rl/gym_mujoco_v2/...`
HDF5 file. That origin server was unreachable at acquisition time (connection
refused on HTTP and HTTPS, repeated attempts), so retrieval used Internet
Archive Wayback Machine snapshots of the exact official URLs (all HTTP 200,
captured 2025-01-02). Minari `mujoco/*-v0` conversions were never
substituted: they are different dataset versions.

## Acquisition protocol

Acquisition is explicit and separate from loading:

```powershell
python -m adaptive_plasticity.datasets --list
python -m adaptive_plasticity.datasets --acquire halfcheetah-medium-v2
python -m adaptive_plasticity.datasets --inspect halfcheetah-medium-v2
```

* Only `acquire_dataset` touches the network; `load_local_dataset` and
  `inspect_dataset` are local-only and raise (with acquisition instructions)
  instead of downloading. Unit tests assert this.
* Raw files are immutable under `data/raw/` and git-ignored (`data/raw/`,
  `*.hdf5`); manifests under `data/manifests/` are tracked.
* Each manifest records canonical ID, filename, official URL, retrieval
  method/URL, snapshot timestamp, byte sizes, SHA-256, observed dimensions,
  transitions, episodes, and validation status.

`halfcheetah-medium-v2` was acquired and validated first, alone. The
remaining five were acquired only after that source and format were confirmed
legitimate and compatible (same official-URL pattern, same archive batch,
same HDF5/D4RL schema). No `medium-replay-v2` blocker occurred: all three
replay datasets resolved from the same trustworthy source.

## Tests

`python -m pytest -q`: unit tests in `tests/test_datasets.py` (9 tests) use
only small synthetic HDF5 fixtures generated at runtime — no network, no real
datasets. They cover registry integrity (6 entries, official URLs, no Minari
substitution), schema accept/reject paths, episode-boundary counting,
trailing-tail reporting, deterministic sampling, loader-refuses-download, and
inspect/manifest round-trips.

## Not implemented

Dataset acquisition/validation only. No algorithms, no training, no
normalization, no preprocessing, no experiments.
