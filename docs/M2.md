# M2: Environment and Dataset Validation

## Validated scope

M2 validates the runtime and dependency interface only. It creates, resets, and takes one action in `HalfCheetah-v5`, `Hopper-v5`, and `Walker2d-v5`. Each validation repeats a fixed-seed reset in a separately created environment and requires equivalent observations. No episode rollout or training is performed.

Use Python 3.11 on Windows PowerShell:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
python --version
python -c "import sys; print(sys.executable)"
python -m pytest -q
python -m adaptive_plasticity.environment_validation
```

The validation command reports Python, PyTorch, CUDA/GPU (when available), Gymnasium, MuJoCo, and Minari versions. CUDA is optional; CPU operation is supported.

## Minari API and dataset status

The M2 script enumerates locally stored datasets with `minari.list_local_datasets()` and, when reachable, queries the remote catalogues with `minari.list_remote_datasets(prefix=...)` for the `D4RL` and `mujoco` namespaces. The latter retrieves catalogue metadata only. It never calls `download_dataset` or `load_dataset`, so it cannot silently download a dataset. The installed API is reported dynamically and supports the standard loading pattern `minari.load_dataset(dataset_id)` after a dataset has explicitly been acquired. Remote catalogue access requires the `huggingface_hub` package (a declared project dependency); if it is unreachable, the report records `remote_catalogue_accessible: false` instead of failing.

The intended HalfCheetah, Hopper, and Walker2d medium and medium-replay offline datasets are **NOT YET VALIDATED AS LOCALLY AVAILABLE** unless the validation report lists them. M2 intentionally does not download them or claim a particular dataset identifier; this must be resolved explicitly before an offline-RL milestone. Dataset metadata (observation/action dimensions, rewards, terminations, episode boundaries, episode count, and transitions) is likewise **NOT YET VALIDATED** until one of those datasets is explicitly made locally available.

Catalogue finding (metadata only, no download): the `D4RL/` namespace contains no HalfCheetah/Hopper/Walker2d entries. The `mujoco/` namespace lists `mujoco/{halfcheetah,hopper,walker2d}/{simple,medium,expert}-v0`, so the medium variants resolve remotely as identifiers. No `medium-replay` variants for these three environments were observed in the remote catalogue. Local availability remains zero; acquisition is deferred to M3.
